# Fingerprint Engine

Commercial fingerprint runtime architecture.

## Modules

```
fingerprint-engine
├── canvas
├── webgl
├── audio
├── font
├── timezone
├── language
├── navigator
├── hardware
├── media
└── webrtc
```

## Template modes

- Random
- Fixed
- Custom

Fingerprint templates will be bound to browser profiles and loaded by Browser Runtime.
